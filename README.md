# Proyecto-Python-Mod1
Es un proyecto basico para poner a prueba los conocimientos adquiridos durante el modulo 1 a traves de la creacion de un inventario interactivo

Student Management System
Description
This is a console-based application designed for educational administrative assistants to manage student information efficiently. The system allows for complete CRUD (Create, Read, Update, Delete) operations, ensuring that student data is handled through structured memory using lists and dictionaries.
Features
The system includes the following core functionalities:
 * Register Students: Add new students with a unique ID, name, age, course/program, and status.
 * View All Students: Display a complete list of all registered students.
 * Search Students: Locate a specific student using criteria such as their ID or Name.
 * Update Information: Modify existing data for a specific student.
 * Delete Students: Remove student records from the system.
 * Data Persistence (Bonus): Capability to save and load data using .json, .csv, or .txt files to maintain information between sessions.
Technical Specifications
 * Modular Design: Every feature is encapsulated within specific functions with parameters and return values.
 * Data Structures: Utilizes a list of dictionaries to store student records dynamically.
 * Error Handling: Basic exception handling to prevent the program from crashing during invalid inputs.
 * Clean Code: Written following readability standards and documented with clear comments in English.
How to Run
 * Ensure you have Python 3.x installed on your system.
 * Clone or download the project files.
 * Open your terminal or command prompt.
 * Navigate to the project directory.
 * Run the application using the following command:
   python main.py

Usage Example
Upon execution, you will see an interactive menu:
 * Select Option 1 to register a student.
 * Enter the required details (ID, Name, Age, etc.).
 * Select Option 2 to verify the student appears in the general list.
 * Use the Search or Update functions to manage the specific record.
 * Choose the Exit option to close the program safely.
